## Stack

## Users

- **1순위: 외부 방문자** — 졸업한 OB, 타 대학 금융학회, 금융권 기업·실무자. HYFE가 어떤 수준의 학회인지, 무엇을 해왔는지 판단하러 들어온다. (2026-11-11 사용자 결정)
- **2순위: 현재 학회원** — 레포트 열람, 회원 전용 페이지, 자료 다운로드를 쓴다. 관리자(임원진)가 가입 승인과 자료 공개를 관리한다.
- 3순위: 지원 예정 한양대생 — 금융권에 관심 있는 학생(전공·학년·학번 무관)이 팀을 고르고 지원을 결심한다.
- (순위는 2026-11-11 사용자 결정. 2·3순위를 사용자가 직접 바로잡음)

## Product Purpose

한양금융공학회(HYFE)의 공식 홈페이지. 기존 사이트(hyfe-website.vercel.app)의 **기능을 100% 그대로 유지**하면서 겉모습만 새로 만든다. 성공 기준은 외부 방문자가 첫 화면과 소개만 보고도 "금융 전반을 체계적으로 다루는 수준 있는 학회"라고 판단하는 것, 그리고 기존 기능(가입 승인, 로그인, 레포트 게시판, 리크루팅 자료 다운로드)이 하나도 빠지지 않는 것이다.

## Positioning

**리서치·IBD·파생상품·퀀트 4개 팀으로 금융 전반을 한 학회에서 다룬다.** 가치투자 한 분야에 집중하는 다른 학회(RISK, KUVIC, STOCKWARS)와 달리, HYFE는 기업분석부터 IB 딜, 파생상품 프라이싱, 퀀트 모델링까지 4개 분야를 각각 교육(Lv1) → 실습(Lv2) → 프로젝트(Lv3) 3단계 커리큘럼으로 운영한다. 사이트에서 가장 앞세울 강점은 이것 하나다. (2026-11-11 사용자 결정)

## Operating Context

- 학기별 학회원 40~50명, 4개 팀 각 10명 내외. 매주 월·목 19:00~22:00 정규 세션.
- 공통 세션: 팀 연합 스터디 발표(각 팀 1명씩 4인 1조), OB 초청 강연, 타 학회 학술 교류, 대회·공모전 참가.
- 팀별 커리큘럼(26-2 기준)
  - 리서치: 기업분석 세미나·Valuation 이론 → PER, EV/EBITDA, DCF 모델링 → 산업·기업 심층 보고서 작성·발표, 대회 참가
  - IBD: IB 업무 구조, LBO/Mezzanine → DCF 기반 Financial 모델링, M&A/IPO case study → 실제 사례 기반 IM(투자제안서) 작성
  - 파생상품: 옵션·선물·스왑 기초 → 파생상품 프라이싱 실습, 그릭스 기반 리스크 관리 → FICC 솔루션 피치북, 매크로 리포트
  - 퀀트: Python 기초 → Portfolio Management 모델, Python 실습 → 주제별 팀 프로젝트, 논문의 한국시장 접목
- 리크루팅: 매 학기 모집. 노션에서 지원서 다운로드 → 이메일 제출 → 서류 발표 → 대면 면접(1차 인적성, 2차 팀별 금융 지식, 리서치는 스탁피치 기반). Zoom 설명회 운영.
- 지원 자격: 금융권에 관심 있는 한양대생, 두 학기 이상 같은 팀에서 활동 가능, 출결 규정 준수.
- 참가 대회: 타임폴리오 모의투자대회, 월드퀀트 IQC, CFA 리서치 챌린지, DB GAPS 투자대회, DB 보험금융공모전.
- 외부 채널: 인스타그램 @hanyang_hyfe, 네이버 카페 cafe.naver.com/hanyangfe, 학회 이메일 hanyanghyfe@naver.com.

- **기능 명세는 기존 사이트와 동일**(상세: `HYFE_홈페이지_디자인_학습노트_v3.md` 1장). 메뉴 HOME / ABOUT / REPORTS / RECRUITING / MEMBER, JOIN · LOGIN, 모바일 메뉴, 하위 페이지 브레드크럼.
  - `/` `/about` `/curriculum` `/history` `/alumni` `/reports`(분류 탭·검색·표·페이지네이션) `/recruiting`(상태 배지·일정·지원서 다운로드·FAQ) `/member`(로그인 필요) `/signup`(관리자 승인 후 가입) `/login`
- **내용은 26-2 HYFE 홍보자료를 기준**으로 한다. 기존 사이트와 다를 때 홍보자료가 이긴다. (2026-11-11 사용자 결정)
  - 설립 연도: 2007년 (기존 사이트 2011 → 교체)
  - 알럼나이: 현직 450여 명 (기존 사이트 120+ → 교체)
  - 팀: 리서치 / IBD / 파생상품 / 퀀트

  - 리크루팅 일정·상태 배지를 관리자가 바꿀 수 있게 할지(기존 사이트는 지난 날짜로 고정)

## Product Principles

1. **4개 팀이 이야기의 뼈대다.** 소개·커리큘럼·레포트가 모두 리서치·IBD·파생상품·퀀트 구조로 읽혀야 한다.
2. **외부인이 3초 안에 수준을 판단할 수 있어야 한다.** 근거 있는 사실(2007년, 450여 명, 3단계 커리큘럼, 참가 대회)로 말하고 수식어로 말하지 않는다.
3. **기능은 하나도 빼지 않는다.** 바뀌는 것은 겉모습과 최신 내용뿐이다.
4. **확인된 사실만 쓴다.** 숫자·로고·후기는 출처가 있을 때만 넣는다.
5. **회원 영역은 도구답게.** 게시판·로그인·자료실은 장식보다 빠르고 정확하게.
