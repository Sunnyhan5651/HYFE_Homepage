# HYFE UI Mockup Prompt Set

Mode: built-in image generation tool via the `imagegen` skill.

Common direction:
- Create high-fidelity desktop frontend UI mockups for HYFE, Hanyang University Financial Engineering Society.
- Use Korea University RISK reference HTML only for structural inspiration: sticky header, large dark hero, breadcrumb, two-level sub navigation, section layouts, board lists, timeline/history, recruitment cards.
- Do not replicate RISK branding, logo, wording, or visual style.
- Brand tone: sophisticated, institutional, premium but restrained, financial research / investment society, clean and implementation-ready.
- Palette: `#1D2475`, `#111853`, `#080D2B`, `#E9ECFF`, `#3F3D42`, `#E5E8F0`, `#FFFFFF`, `#111827`, `#6B7280`.
- Typography direction: Korean UI similar to Pretendard / Noto Sans KR, English UI similar to Inter.
- Header labels: HOME / ABOUT / REPORTS / RECRUITING / MEMBER, with JOIN / LOGIN or logged-in user controls.
- Footer: dark navy HYFE footer with intro, contact, quick links, copyright.
- Avoid: lorem ipsum, random gibberish, cute/startup-gimmick styling, excessive gradients, copied Korea University/RISK elements.
